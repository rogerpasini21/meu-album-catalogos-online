# Catálogos dos álbuns online

Pacotes de álbuns para download pelo aplicativo Meu Álbum de Figurinhas. Este repositório não contém o código do aplicativo, dados pessoais, backups ou credenciais.

Cada pacote ZIP contém album.json e imagens de seções compactadas. Os downloads do aplicativo usam uma versão fixa e conferem tamanho e SHA-256 antes de extrair ou instalar. As capas da biblioteca continuam locais na APK; somente o conteúdo dos álbuns online é baixado.

Repositório público para leitura, sem colaboradores externos com acesso de escrita. Imagens e marcas pertencem aos respectivos titulares.
